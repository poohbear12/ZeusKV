

# ZeusKV
ZeusKV 是一个高性能的分布式 KV 存储系统，旨在提供快速的键值存储和检索功能。

## 特性
1. **高性能**：通过优化数据结构和序列化机制，ZeusKV 提供了出色的读写性能。
2. **多种数据结构**：支持字符串、列表、哈希表、集合和有序集合等常用 Redis 数据结构。
3. **持久化支持**：支持 AOF（Append Only File）日志和 RDB（Redis Database Backup）快照两种持久化方式。
4. **集群支持**：具备主从复制和集群搭建的能力，便于扩展和高可用部署。
5. **内存优化**：内存占用经过优化，确保高效利用资源。

## 性能对比
以下是一些性能对比，以帮助您了解 ZeusKV 的性能优势：
1. **序列化与反序列化性能**：以 KVObject 为基准，对比不同数据结构的序列化和反序列化效率。
2. **读写性能**：以 KVBytes 为基准，展示了 ZeusKV 在读写操作上的卓越表现。
3. **哈希分布均衡**：负载因子测试表明，ZeusKV 在不同数据分布场景下保持了良好的平衡性。

## 启动流程
1. **加载配置文件**：从配置文件中读取必要的参数。
2. **检查配置环境**：验证配置的正确性和完整性。
3. **容器启动**：初始化 RedisCore 和其他核心组件。
4. **Netty启动**：启动 Netty 服务器以处理网络请求。

## 重构优化
- **服务连接**：优化了服务间的连接机制，以提高稳定性和响应速度。
- **协议解析**：改进了 RESP 协议的解析逻辑，减少处理延迟。
- **基础数据结构**：对 Dict、ExpiresDict、Sds、SkipList 等数据结构进行了性能优化。
- **持久化机制**：AOF 日志和 RDB 快照的实现经过优化，确保数据安全和快速恢复。

## 使用示例
以下是如何使用 ZeusKV 的一些简单示例：
- **存储和获取数据**：使用 RedisString 类存储和获取字符串数据。
- **列表操作**：通过 RedisList 类进行列表的推入和弹出操作。
- **哈希操作**：使用 RedisHash 类进行哈希表的键值操作。
- **集合和有序集合**：通过 RedisSet 和 RedisZSet 类进行集合和有序集合的管理。
